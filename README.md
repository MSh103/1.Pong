# Pong Clone

A Pong clone written in C++ using raylib.

## Requirements

- Visual Studio 2022 (or newer)
- Premake5
- Windows

## Building

1. Clone the repository.
2. Run:

```bat
GenerateProjects.bat
```

3. Open `Pong.slnx`.
4. Build the `Application` project.
5. Press F5.

## Third-party

- raylib (included in `Thirdparty/`)
